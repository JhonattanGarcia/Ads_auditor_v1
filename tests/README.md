# Pruebas

unit/: reglas puras, perfiles, URLs, fechas y precedencia.
integration/: SQLite, adaptadores, importacion y respaldos.
e2e/: escenarios CA-01 a CA-15 y E2E-A/B/C del documento funcional.
fixtures/: datos ficticios reproducibles sin credenciales ni evidencia real.

Todavia no se incluyen pruebas de negocio: se incorporaran con cada comportamiento implementado.
